# 📌 Project Overview

This project presents a comprehensive analytics dashboard built using the **Google Play Store Dataset**.  
The objective of this project is to analyze app performance, installs, ratings, reviews, revenue trends, and user engagement using advanced data visualization and business intelligence techniques.

The project includes multiple interactive analytical dashboards and visual reports developed using **Python, Pandas, Plotly, and Google Colab**.

---

# 🎯 Project Objectives

- Analyze app installs and ratings
- Compare free vs paid applications
- Study category-wise app performance
- Identify install growth trends over time
- Perform sentiment-based analytics
- Build interactive and professional dashboards
- Implement internship dashboard tasks on the same dataset
